## 🏆 Featured Projects

### 💰 Contabilia — SaaS de contabilidad e IA
> Monorepo con API NestJS + Frontend Next.js para conciliación bancaria automatizada con IA. Motor de reglas + embeddings, cash application, aprendizaje continuo.

**Key Features:**
- 12 NestJS modules (ingestion, matching, learning, dashboard)
- AI-powered bank reconciliation with semantic similarity
- Continuous learning from user confirmations
- Swagger/OpenAPI documentation
- JWT Auth + Multi-tenant architecture
- CI/CD with GitHub Actions

---

### ❄️ Carnetruck — IoT Cold-Chain Monitoring
> Plataforma de monitoreo IoT para exportación cárnica. Datos de sensores en tiempo real con integridad SHA-256 encadenada y certificados PDF regulatorios.

**Key Features:**
- Immutable SHA-256 hash chain (tamper-evident)
- Real-time alerts (temperature, door, tamper)
- Regulatory PDF certificates (China GACC, UE, USDA-FSIS)
- Multi-tenant JWT auth
- Docker Compose full stack
- Rate limiting + request tracking

---

### ⚡ IronMind — 100% Local RAG Coach
> Coach de fitness RAG que corre 100% en local con GPU AMD. Ingiere videos de YouTube, transcribe con Whisper, y responde citando el video y minuto exacto.

**Key Features:**
- 100% local — zero cloud dependencies
- YouTube → Whisper → Embeddings → RAG pipeline
- Qwen3-14B on RX 9070 XT (Vulkan backend)
- Real-time streaming responses
- Source citations with exact video timestamps
- Vanilla JS premium UI
